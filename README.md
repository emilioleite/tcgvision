# TCG Vision

MVP PWA para reconhecimento de cartas de Magic: The Gathering usando a câmera do celular.

## Escopo atual

- abrir a câmera traseira;
- detectar uma carta mostrada à câmera;
- identificar a carta localmente com CollectorVision;
- consultar o Scryfall pelo ID reconhecido;
- mostrar nome, imagem e confiança na tela.

O reconhecimento roda no navegador. Os modelos e o runtime do CollectorVision são preparados fora do Git para não inflar o repositório.
